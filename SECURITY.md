# Security Policy

## Supported Versions

As OpenSpatial is currently in active development, security fixes will generally be provided only for the latest release.

| Version | Supported |
|----------|----------|
| Latest release | ✅ |
| Older releases | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability in OpenSpatial, please do not open a public issue.

Instead, use GitHub Security Advisories to report the issue privately.

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested mitigation or fix

Reports will be reviewed as quickly as possible.

---

## Disclosure Policy

After a vulnerability has been confirmed and addressed, information may be disclosed publicly through:

- GitHub Security Advisories
- Release notes
- CHANGELOG entries

The goal is to provide users with clear guidance on affected versions and available fixes.
